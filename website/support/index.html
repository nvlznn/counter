Using Counters

  • Tap + at the top to add a counter.
  • Tap + on a row to count.
  • Tap a row to edit.
  • Swipe left to delete.

Reinstalling

Counters come back if iCloud is on for the app.

Not syncing

Use the same Apple ID on each device, and turn on Counters in Settings → iCloud. Syncing can take a minute.
